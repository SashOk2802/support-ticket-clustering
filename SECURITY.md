# Данные и секреты

Не добавляй в публичный репозиторий `.env`, токены, пользовательские обращения, внутренние адреса, документы практики или результаты с примерами текстов. Имя `anon` не гарантирует обезличивание.

Для своих данных используй `datasets/`, для результатов — `results/`. Эти файлы исключены из Git. `.env.example` содержит только пустые значения ключей и публичную конфигурацию провайдера.

Кластеризация и вычисление эмбеддингов выполняются локально. Первый запуск трансформера может загружать модель с Hugging Face. LLM-названия требуют двух явных флагов: `--llm-labels --allow-text-upload`; в этом режиме провайдер получает ключевые слова и примеры текстов.

Перед коммитом проверь список файлов и запусти:

```bash
git diff --cached --stat
python scripts/check_publication.py --history
```

Проверка использует явный список допустимых файлов и ищет типичные ключи, приватные ключи, контакты, IP и локальные пользовательские пути. Совпавшее значение не выводится. CI повторяет аудит на полной истории. Эти проверки не заменяют чтение каждого нового публичного файла: произвольные персональные сведения могут не совпасть с шаблонами.

Если секрет когда-либо был опубликован, сначала отзови его у провайдера и выпусти новый, затем очисти историю. Удаление строки в последнем коммите не удаляет её из предыдущих коммитов, форков и клонов. Никогда не прикладывай сам секрет к публичному issue.
