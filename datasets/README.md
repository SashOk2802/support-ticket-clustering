# Датасеты

`demo_tickets.csv` содержит **32 вымышленных обращения**, написанных специально для публичного примера. Здесь нет скопированных обращений, адресов, аккаунтов или серверных реквизитов. Четыре учебные категории: `billing`, `dns`, `server`, `email`.

## Вход для кластеризации

CSV с разделителем `,`, `;` или табуляцией либо XLSX:

| Колонка | Требование |
|---|---|
| `text` | Непустой текст; минимум 3 текста, для UMAP минимум 4 |
| `ticket_id` | Необязательный идентификатор |
| `category` | Необязательная эталонная категория для метрик; обязательна для benchmark |

Пример:

```csv
ticket_id,text,category
demo-001,Не проходит оплата счёта.,billing
demo-002,Не обновляется DNS запись домена.,dns
demo-003,Почтовый клиент не отправляет письма.,email
```

Benchmark требует минимум 10 непустых размеченных текстов и две категории. Препроцессинг создаёт неразмеченную выборку; `category` нужно добавить отдельно.

## Вход для препроцессинга

`preprocessing.py` читает два локальных файла:

| Файл | Обязательные колонки |
|---|---|
| Заголовки обращений (`--tickets`) | `ticket_id`, `subject` |
| Сообщения (`--messages`) | `ticket_id`, `ticket_message`, `ticket_message_author` |

Автор пользовательского сообщения должен быть обозначен `User`. Код берёт первое сообщение в порядке исходного файла, объединяет его с темой и сохраняет только `ticket_id` и `text`. Заголовки должны содержать одну строку на `ticket_id`. Выборка воспроизводимо перемешивается с seed 42; если обращений меньше заданного размера, берутся все.

```bash
python preprocessing.py --tickets datasets/tickets_anon.csv --messages datasets/ticket_messages_anon.csv
```

Этот шаг очищает пробелы, но не удаляет персональные или служебные сведения. Название файла с `anon` не доказывает, что его безопасно публиковать. Собственные данные храни локально: всё в этой папке, кроме демо и этого README, исключено из Git.
