# Результаты исходного эксперимента

В этой папке опубликованы только агрегированные данные исходного исследования:

- [benchmark_results.csv](benchmark_results.csv): все 27 комбинаций, гиперпараметры и метрики.
- [experiment_summary.json](experiment_summary.json): сохранённая конфигурация с максимальным NMI.
- [benchmark_nmi_chart.png](benchmark_nmi_chart.png): девять лучших комбинаций с долей текстов вне шума.

CSV экспортирован из исходной таблицы результатов с проверкой схемы и типов. Он не содержит идентификаторов обращений, текстов, ключевых слов или примеров из частных данных. График построен заново из этого публичного CSV; команда: `python scripts/plot_benchmark.py`.

## Методика

Исходная размеченная выборка — 200 обращений. Сравнивались BGE-M3, multilingual MiniLM и ruBERT-tiny2; UMAP, PCA и t-SNE; HDBSCAN, K-Means и GMM. Каждая из 27 комбинаций получила 30 попыток Optuna с seed 42.

Эмбеддинги нормализованы. Цель Optuna — NMI с двумя штрафами: за долю шума больше 40% и за число кластеров меньше трёх. Сохранённая итоговая таблица ранжируется по NMI. Время `Time_Execution` относится к оптимизации конкретной комбинации и не включает первоначальное вычисление эмбеддингов. Это не сопоставимый между компьютерами latency-бенчмарк.

ARI, NMI и silhouette рассчитываются **после исключения HDBSCAN-шума**. Поэтому высокие показатели нужно смотреть вместе с `Noise_Pct`. Для K-Means/GMM шум равен нулю.

## Пределы выводов

Гиперпараметры подбирались на той же выборке, по которой вычислялись итоговые метрики. Отдельного holdout-набора, доверительных интервалов и повторов по разным seed не было. Малый объём, большое число попыток и исключение шума ограничивают выводы о качестве на новых данных.

Исходные тексты не опубликованы. Поэтому точное воспроизведение этих исторических чисел из публичного репозитория невозможно. Демо воспроизводит устройство пайплайна на вымышленных текстах, а не исходное исследование. После исправлений для публикации полный эксперимент не пересчитывался; версия зависимостей для демо не описывает историческое окружение эксперимента.
